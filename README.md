# Калькулятор Закону Ома та Потужності ⚡️

Мобільний додаток на React Native для швидкого розрахунку основних електричних параметрів: напруги (U), струму (I), опору (R) та потужності (P).

Додаток працює за принципом автодоповнення: достатньо ввести будь-які два відомі значення, і програма автоматично розрахує два інших.

![Інтерфейс](assets/images/scrn.jpg)

## Основні можливості

* **Автоматичний розрахунок:** Миттєве обчислення параметрів на основі двох введених змінних.
* **Темна тема:** Сучасний та мінімалістичний інтерфейс (Material Design vibes).
* **Валідація вводу:** Очищення зайвих полів при зміні параметрів та захист від некоректних значень.
* **Кросплатформність:** Працює на iOS та Android.

## Встановлення та запуск

1. **Клонуй репозиторій:**
   ```bash
   git clone https://github.com/69-Lukash/ohm-calc
   ```

2. **Встанови залежності:**
   ```bash
   npm install
   ```

3. **Запусти проект:**
   ```bash
   npx expo start
   ```

## Стек технологій

* **React Native**
* **React Hooks** (`useState`, `useEffect`)
* **StyleSheet** (кастомний дизайн без важких бібліотек)
